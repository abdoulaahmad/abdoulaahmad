<details>
<summary><b>💸 Aptick — Decentralized Billing System</b></summary>
<br>
**Aptick** is a revolutionary **decentralized billing and payment system** built on the **Aptos blockchain**, enabling seamless usage-based billing for Web3 services.
<br>
**Stack:** Aptos Move · Next.js · TypeScript · MIT License

#### 🌟 Overview
Aptick transforms how services are billed and paid for in Web3. It enables:
- Providers to register services and set pricing models
- Users to prepay for services with APT tokens
- On-chain usage tracking with automatic payments
- Automatic refunds for unused balance

Perfect for **APIs, SaaS, cloud services, data storage, and bandwidth billing.**

#### ✨ Key Features
- 🏗️ **Smart Contract Core:** Trustless billing, escrow system, automatic payments, transparent pricing
- 💼 **Service Providers:** Register pricing, auto revenue collection, analytics
- 👥 **Service Users:** Prepay with APT, real-time balance, automatic refunds
- 🔧 **Developer SDK:** TypeScript SDK, React hooks, multi-wallet support, documentation

[🔗 View Repo](https://github.com/abdoulaahmad/Aptick)
</details>
